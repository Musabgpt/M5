# M5 — Open AI Coding Workbench

M5 is an independent, open-source, Android-first coding workbench with an agent runtime in Termux and an integrated on-device IDE. The aim is functional parity with modern agentic code editors, not copying proprietary Cursor code or branding.

**Status:** active implementation. No claim of full Cursor parity or verified physical-device support until CI and device acceptance prove it.

The original free gateway families from M4 remain supported: FreeLLMPool, GPT4Free, free-llm-gateway, free-llm-api. Availability and quota are not guaranteed.

See the development branch and its pull request for implementation, build instructions, test evidence and limitations.
